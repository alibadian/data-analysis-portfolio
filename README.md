Data Analysis Portfolio

A collection of data analysis projects built with Python.

Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

Projects

1. Sales Data Analysis

- Calculate total revenue and profit.
- Identify the best-selling product.
- Analyze monthly revenue.
- Generate CSV reports and charts.

File: "sales_analysis.py"

2. Product Price Analysis

- Analyze product prices and ratings.
- Identify the cheapest and most expensive products.
- Compare average prices across brands.
- Export results to Excel.

File: "product_analysis.py"

3. Customer Behavior Analysis

- Calculate total spending per customer.
- Analyze order counts and average order values.
- Segment customers by spending.
- Generate customer reports and charts.

File: "customer_analysis.py"

Installation

Install the required libraries:

pip install pandas numpy matplotlib openpyxl

Running the Projects

Run each project with Python:

python sales_analysis.py
python product_analysis.py
python customer_analysis.py

Data

The projects currently use sample datasets for demonstration and practice.
